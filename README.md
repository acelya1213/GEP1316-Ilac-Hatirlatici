# GEP1316 – İlaç ve Tedavi Saatleri Hatırlatıcı

**Öğrenci:** Açelya Çayırcı  
**Bölüm:** Eczacılık  
**Ders:** GEP1316 Kodlama Okuryazarlığı  
**Dönem:** 2026–2027 Güz

## 1. Projenin Amacı

Bu proje, ilaç kullanım saatlerinin düzenli şekilde planlanmasını kolaylaştırmak amacıyla Python programlama dili kullanılarak geliştirilmiştir.

Uygulama, kullanıcı tarafından girilen ilaç bilgilerine göre bir tedavi takvimi oluşturmayı amaçlamaktadır.

## 2. Uygulamanın Özellikleri

- İlaç adı ve kullanım bilgilerinin girilmesi
- Başlangıç saati ve kullanım aralığına göre ilaç saatlerinin hesaplanması
- Tedavi planının görüntülenmesi
- Kullanıcı girişlerinin kontrol edilmesi
- İlaç kayıtlarının dosyada saklanması
- Menü üzerinden farklı işlemlerin seçilmesi

## 3. Kullanılan Teknolojiler

- Python
- Visual Studio Code veya Python destekleyen bir geliştirme ortamı
- GitHub
- ChatGPT (yapay zekâ destekli geliştirme)

## 4. Programlama Yapıları

Projede aşağıdaki Python yapılarından yararlanılmıştır:

- Değişkenler ve operatörler
- if / elif / else karar yapıları
- for ve while döngüleri
- Fonksiyonlar
- Listeler ve sözlükler
- Dosya işlemleri
- Tarih ve saat hesaplamaları

## 5. Program Nasıl Çalıştırılır?

1. Bilgisayarda Python 3 kurulu olmalıdır.
2. GitHub üzerinden proje dosyası indirilir.
3. Python dosyası uygun bir geliştirme ortamında açılır.
4. Program çalıştırılır.
5. Ekrandaki menüden istenilen işlem seçilir.
6. İlaç bilgileri girilerek kullanım planı oluşturulur.

## 6. Test ve Hata Kontrolü

Proje için normal ve hatalı kullanıcı girişlerini kapsayan test senaryoları hazırlanmıştır.

Örnek testler:

- 08:30 saatinin geçerli kabul edilmesi
- 25:99 gibi hatalı saatlerin reddedilmesi
- Boş saat girişinin reddedilmesi
- 8 saat aralıklarla ilaç saatlerinin hesaplanması
- Gece yarısını geçen saatlerin doğru hesaplanması

## 7. Yapay Zekâ Kullanımı

Projenin geliştirilmesinde OpenAI ChatGPT aracından kod oluşturma, algoritma tasarlama, hata kontrolü ve rapor hazırlama aşamalarında destek alınmıştır.
